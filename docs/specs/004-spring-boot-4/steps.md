# Implementation Steps: Spring Boot 4

Spec: [`design.md`](design.md) · [`behaviors.md`](behaviors.md) · Issue #8

`java-parent` has `packaging=pom` and no Java sources, so the scenarios are exercised
against a throwaway probe child, per [Acceptance](design.md#acceptance).

---

## Step 1: Bump the managed versions and the Java baseline

- [x] Project version `2.0.0-SNAPSHOT`
- [x] `spring-boot.version` 4.1.2, `springdoc.version` 3.2.0, `swagger.version` 2.2.55,
      `swagger-ui.version` 5.34.0, `jspecify.version` 1.0.1
- [x] `maven.compiler.source` / `target` and `enforcer.requiredJavaVersion` 25
- [x] Comments: Boot major defines the parent major; jspecify must not fall below Boot

**Acceptance criteria:**
- [x] All six BOM/artifact versions exist on Maven Central
- [x] Swagger values match `<swagger-api.version>` / `<swagger-ui.version>` in
      `springdoc-openapi-3.2.0.pom`; its parent is `spring-boot-starter-parent` 4.1.2
- [x] `project.build.outputTimestamp` unchanged (`2026-09-10T17:19:06Z`)

**Related behaviors:** Spring Boot 4 is managed · The OpenAPI stack matches Boot 4 ·
jspecify is not pinned below Boot · Reproducible-build settings are unchanged

---

## Step 2: Move this repository's own toolchain to Java 25

- [x] `java-version: "25"` in `build.yml`, `snapshot.yml`, `release.yml`
- [x] `.sdkmanrc` → `java=25`

**Acceptance criteria:**
- [x] `./mvnw -Pfull-build clean verify` passes on Temurin 25.0.1

**Related behaviors:** The parent builds and validates on JDK 25

---

## Step 3: Prove the result against a probe child

- [x] `./mvnw -N install`, probe child with `spring-boot-starter-webmvc`,
      `springdoc-openapi-starter-webmvc-ui`, `jspecify`, `testcontainers-junit-jupiter`
      (no versions) and one record using `@Nullable`
- [x] Resolve the tree, compile on JDK 25, validate on JDK 21

**Acceptance criteria:**
- [x] Tree matches the expected versions (see coverage table)
- [x] `Hello.class` major version 69
- [x] JDK 21: `RequireJavaVersion` fails — "version 21.0.11 which is not in the allowed
      range [25,)"
